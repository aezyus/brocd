# BroCD
A friendly mobile-first PWA for practicing a pause before mental compulsions. User brief: sage/peach wellness references, broad OCD themes, touch grounding, context logging, actual session history, small install prompt, Neon persistence, Vercel-ready.
## Platform
Web PWA, responsive desktop and mobile.
## Safety and privacy
Support tool, not clinically validated treatment. No reassurance chat, pass/fail scoring, promised anxiety reduction, fixed clinical minimum, or invented time savings. Optional context; private browser identity; no thought narratives.
## Assumptions
Superseded by the final scope below: the initial implementation used a browser-specific session; the final app requires managed accounts and supports cross-device history. Design follows supplied references without another approval round, per user request to work now quickly.

## Final scope updates
User requested a normal public landing page, with the app behind account login. Neon managed email/password auth is enabled. Sign-up, sign-in, sign-out, session restoration, and per-account journal access are implemented. User also requested completion summaries and visual separation by OCD theme: completion shows the chosen theme, and journey includes count/time distributions and filtering. Password recovery/verification screens use managed email OTP; real inbox delivery remains a deployment verification step.
